# Market State Lab

美股盘后市场分析器，供人工决策使用。只读公开数据与 IBKR TWS，不读账户、不下单、不自动交易。

每次运行回答五个问题：市场哪些方面变了、现在的行动倾向、支持与反对的证据、有哪些具体防御工具及其成本、什么条件会让这份描述过时。

**第二个问题的答案被预先登记为「证据不足」。** 原因见下一节。这是预期结果，不是今天数据不够。

## 先读这一节：预测层不工作，而且已经量过了

2026-09 的完整审计推翻了本项目此前声称的全部预测价值。四条结论都在 `research.py` 的登记表里，带数字。

**预测层输给一条两行规则。** 在所有预测器都有定义的公共样本上，「取上一个已结算的 20 日波动率三分位，套用滚动转移频率」得到前瞻 Brier **0.5134**；本项目的校准集成是 **0.5721**。

**把持续性放进基底也救不回来。** 在持续性之上加状态层使 Brier 变差 0.0995 到 0.126，全部显著，全部错方向。单是「对持续性重新拟合一次」就损失 0.148。

**回撤优势是降杠杆，不是信号。** 对照 `vol_only` 时每个 haircut 都显著；换成等仓位对照后全部不显著，0.65 档的 CI 是 [−0.0061, +0.0087]。这条登记为**证据不足**，不是有害——两者不是一回事。

**换预测期限也不行。** 126 日上每一个预测器都是 2000–2013 显著、2013–2026 不显著。后半段含 2015、2018、2020、2022，不缺回撤。

### 为什么会错这么久

依次选过三个基准，每一个都是模型能赢的。流程是「挑一个基准，验证赢了」，而不是「挑怀疑者会要求的基准」。中间报了三次成功，还写了一个测试去锁住错误结论。

现在这道闸门是**代码**，不是自觉。`research.py` 里晋级必须逐级、必须预注册全部基准、必须事先指定唯一主指标，前向证据必须来自冻结之后才存在的数据；`Assessment` 在规则未验证时构造任何非 `DATA_INSUFFICIENT` 的倾向会直接抛异常。

## 现在能用的东西

**防御工具比较**（`scripts/protection_table.py`）。从期权链到到期损益的完整链路：链选择 → 确认该到期日真实挂牌的行权价 → 合约认证 → 报价 → 平价质检 → 硬筛选 → 至多三个候选，**并列两个对照**：不新增保护、降低参考暴露。没有排名列——更深的行权价更便宜、保护启动更晚，这是偏好不是最优解。

**市场描述**（`scripts/daily_report.py`）。五个维度各自独立，不合成评分。分位数是**因果的**（只用观测点之前的历史），并且每一行都写明它是历史排名不是概率。维度之间的矛盾作为输出，不被平均掉。

日报第 2 段是操作内容:**历史条件频率**——20 个交易日内出现 5% 跌幅的历史频率、价格在 200 日均线上/下方各自的频率、波动率不低于当前水平时的频率,全部按因果口径计算并标注为频率而非概率——加上参考暴露建议。方法声明、研究等级等自省内容收在第 7 段,不占用操作判断的阅读路径。

**数据质量与溯源**。合约身份与单位口径在 `data/contracts.py`（conId 才是身份，未复权/复权序列不可互比），原始响应写一次不可覆盖，快照按内容寻址、按（交易日 × 运行参数）分修订链，用途资格是授予的而不是到货就有的。计划 §16.1 的故障注入矩阵 **11/12 覆盖**（最后一条需要特征层在验证快照上重建）。

**跨源核验**（`scripts/reconcile_spy.py`）。SPY 日线 TWS 对 Yahoo，251 个交易日最大相对差 4.6e-08。第二源只能**确认**事件，永远不能**解除**隔离——两个转售同一份坏文件的源会完美一致。

**基准账本**（`evaluation.py`）。`research.py` 点名的四个必备基准在这里被真正计算——命名一个没有东西能测量的门槛，就是让它悄悄变成装饰。26 年 SPY 实测：

| 基准 | 年化收益 | 最大回撤 | 平均仓位 |
|---|---|---|---|
| 一直满仓 | 9.98% | −55.2% | 1.00 |
| 固定低仓位 | 5.99% | −36.7% | 0.60 |
| 波动率目标化（trailing 20d） | 6.40% | −34.4% | 0.72 |
| 波动率目标化（EWMA） | 6.16% | −31.0% | 0.71 |
| 长期趋势规则 | 7.60% | −21.0% | 0.72 |

**它们是门槛，不是推荐。** 波动率目标化的最差情景是 2000-2002 慢熊（2000 年 9 月顶部暴露 0.95），不是 2008；EWMA 变体响应更快，同样的仓位下回撤浅 3.4 个百分点。趋势规则的回撤优势（−21.0%）同样没有被晋级——见下面的 replay 裁决。

**参考暴露建议**是日报第 2 段里唯一有实测记录的数字：目标波动 10% ÷ 当前波动 = 建议暴露，并列 trailing / EWMA / 趋势规则三个数字。它不需要任何预测能力，这是它能出现在报告里的原因。

**趋势规则 replay 裁决（2026-09-09 预注册，`scripts/replay_trend_rule.py`）**：趋势规则作为 5%/20d 事件的预警信号，在 2013-2026 测试窗上事件级召回 0.36，输给频率匹配的波动率规则（0.52），差 0.15 超过预注册的 0.05 门槛——登记为**证据有害**（evidence_of_harm），停在第一级。它的回撤数字因此不能被当作择时能力来用。这条规则输了，是这套闸门想要的输出，不是意外。

## 安装与运行

```powershell
.\bootstrap.ps1
.\.venv\Scripts\python.exe scripts\doctor.py
```

日报（只需公开数据，TWS 不开也能跑）：

```powershell
.\.venv\Scripts\python.exe scripts\daily_report.py
```

`cli run` 走同一个 `run_pipeline`——一次运行一套产物，两条实现迟早会给出两个答案。

TWS 开着时加 `--with-ibkr`，日报第 1 段的跨源核验会用 TWS 作为**真正独立的第二个数据源**（实测 250 个交易日、最大相对差 4.6e-08、0 天超容差）。不加就如实写"无独立第二源"。

**描述层本身不需要 TWS，而且用 Yahoo 更好**：价格是同一个数，但 Yahoo 有 6,710 个交易日的历史（因果分位需要长历史）和 TWS 没有的信用利差。TWS 不可替代的只有期权链。

产出 14 件产物到 `reports/{run_id}/`：`run_manifest.json`、`data_quality_summary.json`、`data_quality_issues.csv`、`source_reconciliation.csv`、`market_evidence.parquet`、`market_assessment.json`、`instrument_candidates.csv`、`scenario_comparison.csv`、`benchmark_ledger.csv`、`data_manifest.csv`、`report.md`、`report.html`,以及中文版 `report_zh.md`、`report_zh.html`(同一份报告结构的两种固定译文,不会漂移成两个答案)。

防御工具表（需要 TWS，收盘后即可，**不必盘中**）：

```powershell
.\.venv\Scripts\python.exe scripts\protection_table.py --symbols SPY,QQQ,IWM
```

TWS 的延迟行情足够——冻结账面就是上一交易日的结算买卖价。更早交易日的期权报价拿不到（`reqHistoricalData` 对期权返回 Error 162），所以历史只能自己往前记：每次运行写一个不可变快照。

## 边界

- **不读持仓**。参考暴露是一个明确声明的标尺（默认 $100,000），报告里任何账户字段都会让 `build_report` 抛异常。
- **只到期损益**。到期前估值需要带离散分红的美式定价库，未验证之前不伪造提前退出盈亏。
- **不排名、不打分**。减仓与买保护回答的是两种不同偏好，市场数据无法在它们之间做选择。
- **「数据不足」「没有合格工具」「风险真实但保护昂贵」「证据冲突」都是正常结果**，按结果渲染，不按失败渲染。

## 测试

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check src tests scripts
```

284 个测试。除了前视偏差防护、故障注入矩阵、平价检验、快照复现之外，还钉住几条口径不变量：未验证的规则不得输出行动倾向、修订不得静默覆盖旧结论、缺失不得转成零、跨源一致不得解除隔离、报告不得出现账户字段、中文报告与英文报告共享同一份结构。
