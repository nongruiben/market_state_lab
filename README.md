# Market State Lab

美股盘后市场风险状态研究框架。只读公开数据与已授权的 IBKR 数据，无下单接口。

## 先读这一节：这个模型不工作

2026-09 的一次完整审计推翻了本项目此前声称的全部预测价值。结论有测量、有置信区间、有双窗口验证。

**预测层输给一条两行规则。** 在所有预测器都有定义的公共样本上，「取上一个已结算的 20 日波动率三分位，套用滚动转移频率」得到前瞻 Brier **0.5134**、命中率 63.1%；本项目的校准集成是 **0.5721** / 55.7%，连历史基率（0.5794 / 59.6%）的命中率都不如。

**把持续性放进基底也救不回来。** 在持续性之上加 `risk_score` 使 Brier 变差 0.0995（CI [−0.185, −0.023]）；加三个 block 变差 0.126；加现有校准集成变差 0.116。全部显著，全部是错方向。单是「对持续性重新拟合一次」就损失 0.148——拟合这个动作本身就是损害。

**回撤优势是降杠杆，不是信号。** 对照 `vol_only` 时每个 haircut 都显著；换成**等仓位对照**（同样的平均仓位、零信号）后全部不显著，0.65 档的 CI 是 [−0.0061, +0.0087]。`vol_only` 平均仓位 0.743，带状态的变体约 0.59，这个差额就是全部效果。

**换预测期限也不行。** 前瞻最大回撤的秩相关：`volatility_20` 随期限衰减（−0.396 → −0.250），`risk_credit` 在 126 日反超（−0.378 vs −0.305），看起来像转机。双窗口验证否决了它——126 日上**每一个**预测器都是 2000–2013 显著、2013–2026 不显著（`risk_credit` −0.612 → −0.119，`volatility_20` −0.454 → −0.113，`risk_rates` 符号翻转）。后半段含 2015、2018、2020、2022，不缺回撤，是这些变量叫不出来。

**所以默认配置里 `high_risk_exposure_haircut: 0.0`**：推荐仓位就是纯波动率目标化，状态层不参与任何仓位决策，只作为观测输出。

### 唯一活下来的东西

**波动率目标化**，因为它不做预测。规则是「近期波动大就少持有」，最大回撤 −55%（一直满仓）→ −25.7%，这是回测里已实现的机械结果，不依赖任何对未来的判断。`volatility_20` 在 2013 年后失去的是「预测回撤」的能力，而这条规则从不需要那个能力。

### 为什么会错这么久

依次选过三个基准，每一个都是模型能赢的：原始的自指 Brier、然后 climatology（对聚集性序列太弱）、然后用 `vol_only` 比回撤（混杂降杠杆）。流程是「挑一个基准，验证赢了」，而不是「挑怀疑者会要求的基准」。中间报了三次成功，还写了一个测试去锁住错误结论。

线索一直在：**连续五个特征家族返回 null，那是天花板在说话，不是五次测量失误。**

## 仍然可靠的部分

前视偏差防护经独立验证（含一个「污染未来数据看拟合温度是否变化」的探针，零影响）、point-in-time 纪律、数据溯源与健康检查、walk-forward 骨架。**这是一个库，不是一个产品。**

## 评估口径

- `model_comparison.csv` 同时给出 `self_consistency_brier`（只是与手写规则的自洽度，**不是准确度**）、`forward_brier`，以及 **两个基准行**：`climatology`（滚动基率）与 `persistence`（本项目该过的门槛）。所有行在**同一个公共样本**上打分，因此列可以纵向比较。
- `decision_value_comparison.csv` 含 buy-and-hold 对照、2bp 交易成本、超额现金 Sharpe 与 `risk_free_coverage`，以及回撤的两种检验：`drawdown_significant_vs_vol_only`（混杂降杠杆，仅保留作连续性）与 `drawdown_significant_vs_matched`（等仓位对照，**这个才隔离信号**）。
- `exposure_tradeoff.csv` 给出 haircut 从 0 到 1 的完整权衡曲线。
- `feature_coverage.csv` 逐特征覆盖率；规则**即使特征完全缺失也会被评估**（此前会静默放行）。
- `data_manifest.csv` 抓取状态、交易日年龄、历史深度与密度、模型可用性。

关于数据源：FRED 的 keyless graph CSV 只对受 ICE 许可的 `hy_oas`/`ig_oas` 截断到约 3 年；穆迪的 `BAA10Y`/`AAA10Y` 在同一端点返回完整历史，无需 key。拿不到全历史时先查该序列是否受许可限制，而不是默认「需要 API key」。

`configs/settings.yml` 里记录了已测试并否决的候选（OFR 分项、CBOE 波动率族、PCA 降维、宏观经济数据、信用利差 block），带测量结果，避免重复劳动。

## 防御工具比较

```powershell
.\.venv\Scripts\python.exe scripts\protection_table.py --symbols SPY,QQQ,IWM
```

对每个标的，把链上的保护性 put 与**两个对照**放进同一张表：不新增保护，以及降到 80% 仓位持现。候选最多三个，对应三个保护深度；没有 score 列可以排序，因为浅一档保护启动更早但更贵，这是偏好不是最优解。两个对照都不是免费的——卖出付价差，而且放弃上涨：$100k SPY 上，降仓 80% 花 4 美元换 -20% 时的 3,996 保护，代价是 +10% 时少赚 2,004；-10% 的 put 只少赚 123。这个取舍就是表的全部意义。

每行带自己的证据：报价基准（冻结/实时）与真实陈旧度（冻结账面按交易日历计龄，不按 tick 推送时刻）、价差、未平仓量、四档报价资格（VALID/DEGRADED/QUARANTINED/UNAVAILABLE），以及被剔除时具体哪个数字没过。收盘后的冻结账面是 VALID——那就是此刻的全部市场；同一份账面在盘中交易时是 DEGRADED，不管承载它的 tick 多新。未平仓量没返回**不构成剔除**：这个 tick 约有一半时间迟到或不来，因缺失 tick 丢掉一个流动合约，和因为一个零接纳一个不流动合约是同一种错。

报价先自检再使用：取每个 put 对面的 call 做**看跌-看涨平价**检验，`C − P` 对行权价须线性、斜率 −e^(−rT)。无套利约束，不需要模型、额外订阅或第二个数据源。容差用报价价差本身，因为中价只能精确到每条腿半个价差。**它检验自洽性，不检验时效性**——四天前冻结的账面同样完美满足恒等式。隐含利率只是斜率的副产品，随表给出标准误：60 点跨度的 31 天梯上是 ±1.7%，所以 SPY 的 +1.6% 和 IWM 的 −3.5% 不是两个事实，是一个没被解析出来的数字。

只算到期损益。到期前估值需要带离散分红的美式定价模型，本项目没有验证过，所以不报。延迟报价不是下单能成交的价。跨标的各按自己标的的参考本金定价，**不构成排名**——QQQ 的 put 不是 SPY 仓位的替代对冲。

## 测试

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check src tests scripts
```

78 个测试。除了前缀不变性（覆盖 `calibrated_p_*` 与 `calibration_temperature`）、合成体制恢复、HMM 前向滤波、数据源健康、新闻时间窗之外，还钉住几条口径不变量：两个 Brier 与两个基准必须同时发布、技能判定必须由数字算出而非断言、`risk_score` 只在必需 block 齐全时才有值、温度缩放不得改变 argmax、离线 fixture 豁免历史深度检查。
